# 🚀 راهنمای سریع XAMPP

## ⚡ **نصب و اجرا در 5 مرحله**

### 1️⃣ **نصب XAMPP**
- دانلود از: https://www.apachefriends.org
- نصب کنید

### 2️⃣ **کپی فایل‌ها**
- فایل‌های پروژه را در `C:\xampp\htdocs\currency-exchange\` کپی کنید

### 3️⃣ **روشن کردن سرویس‌ها**
- XAMPP Control Panel را باز کنید
- **Apache** و **MySQL** را Start کنید

### 4️⃣ **راه‌اندازی دیتابیس**
- مرورگر باز کنید
- آدرس: `http://localhost/currency-exchange/database_simple.php`
- منتظر پیام سبز "همه چیز آماده است!" باشید

### 5️⃣ **ورود به سیستم**
- آدرس: `http://localhost/currency-exchange/`
- **نام کاربری:** admin
- **رمز عبور:** admin123

---

## 🔧 **حل مشکلات سریع**

### ❌ **Apache شروع نمی‌شود**
- Skype را ببندید
- پورت 80 را آزاد کنید

### ❌ **MySQL شروع نمی‌شود**  
- سرویس‌های MySQL دیگر را ببندید
- کامپیوتر را restart کنید

### ❌ **صفحه خالی**
- مسیر فایل‌ها را بررسی کنید
- Apache و MySQL سبز باشند

### ❌ **خطای دیتابیس**
- `http://localhost/currency-exchange/test_db.php` اجرا کنید
