# سیستم مدیریت داشبرد (Dashboard Management System)

یک سیستم مدیریت داشبرد کامل با قابلیت‌های احراز هویت، مدیریت کاربران، کنترل دسترسی، و مدیریت جلسات با PHP، HTML، CSS و JavaScript.

## ویژگی‌ها

### 🔐 احراز هویت و امنیت
- ورود با نام کاربری/ایمیل و رمز عبور
- هش کردن امن رمز عبور
- قفل شدن حساب بعد از 5 تلاش ناموفق
- جلسات امن با پایگاه داده
- خروج خودکار بعد از 30 دقیقه عدم فعالیت
- ردیابی فعالیت کاربران

### 👥 مدیریت کاربران
- ایجاد، ویرایش و حذف کاربران
- سیستم نقش‌ها (مدیر ارشد، مدیر، کاربر)
- کنترل دسترسی‌های جزئی
- مشاهده وضعیت و آخرین ورود کاربران

### 📊 داشبرد
- نمایش آمار کلی سیستم
- فعالیت‌های اخیر کاربران
- اطلاعات جلسه جاری
- جلسات فعال سیستم

### ⏰ مدیریت جلسات
- خروج خودکار بعد از 30 دقیقه
- هشدار 5 دقیقه قبل انقضای جلسه
- امکان تمدید جلسه
- ردیابی فعالیت در زمان واقعی

## نصب و راه‌اندازی

### پیش‌نیازها
- وب سرور (Apache/Nginx)
- PHP 7.4 یا بالاتر
- MySQL 5.7 یا بالاتر
- PDO extension برای PHP

### مراحل نصب

#### 1. دانلود پروژه
```bash
git clone [repository-url]
cd dashboard-system
```

#### 2. راه‌اندازی پایگاه داده
1. یک پایگاه داده MySQL جدید ایجاد کنید:
```sql
CREATE DATABASE dashboard_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

2. جدول‌ها را با اجرای `schema.sql` ایجاد کنید:
```bash
mysql -u your_username -p dashboard_db < schema.sql
```

#### 3. تنظیم اتصال پایگاه داده
فایل `config/database.php` را ویرایش کنید:
```php
private $host = 'localhost';
private $db_name = 'dashboard_db';
private $username = 'your_username';
private $password = 'your_password';
```

#### 4. تنظیم وب سرور
- فایل‌های پروژه را در Document Root قرار دهید
- اطمینان حاصل کنید PHP و MySQL فعال هستند
- مجوزهای فایل‌ها را بررسی کنید

#### 5. اولین اجرا
1. به آدرس سایت مراجعه کنید
2. وارد صفحه login.html شوید
3. از اطلاعات پیش‌فرض استفاده کنید:
   - نام کاربری: `admin`
   - رمز عبور: `admin123`

## API Documentation

### ورود
- **URL:** `api/login.php`
- **Method:** POST
- **Body:**
```json
{
    "username": "admin",
    "password": "admin123"
}
```

### خروج
- **URL:** `api/logout.php`
- **Method:** POST

### بررسی جلسه
- **URL:** `api/session.php`
- **Method:** GET

### مدیریت کاربران
- **URL:** `api/users.php`
- **Methods:** GET, POST, PUT, DELETE

### اقدامات امنیتی پیاده‌سازی شده:
- هش کردن رمز عبور با bcrypt
- محافظت از SQL Injection با Prepared Statements
- ولیدیشن و پاک‌سازی ورودی‌ها
- کنترل دسترسی مبتنی بر نقش
- مدیریت جلسات امن
- قفل کردن حساب در صورت تلاش‌های مشکوک

### توصیه‌های امنیتی:
- رمز عبور پیش‌فرض را تغییر دهید
- از HTTPS استفاده کنید
- پایگاه داده را از دسترسی مستقیم محافظت کنید
- به‌روزرسانی‌های امنیتی را اعمال کنید

## تنظیمات

### زمان انقضای جلسه
در فایل `js/session-manager.js`:
```javascript
this.sessionTimeout = 30 * 60 * 1000; // 30 دقیقه
this.warningTime = 5 * 60 * 1000;     // هشدار 5 دقیقه
```

### دسترسی‌ها
دسترسی‌های سیستم در `schema.sql` تعریف شده‌اند:
- `dashboard_view` - مشاهده داشبرد
- `users_view` - مشاهده کاربران
- `users_create` - ایجاد کاربر
- `users_edit` - ویرایش کاربر
- `users_delete` - حذف کاربر
- و سایر موارد...

## توسعه

### افزودن صفحه جدید:
1. صفحه HTML را در `dashboard.html` اضافه کنید
2. استایل‌های مربوطه را در CSS قرار دهید
3. منطق JavaScript را پیاده‌سازی کنید
4. دسترسی‌های لازم را تعریف کنید

### افزودن API جدید:
1. فایل PHP جدید در پوشه `api/` ایجاد کنید
2. از کلاس‌های موجود استفاده کنید
3. احراز هویت و دسترسی را بررسی کنید

## مشکلات متداول

### خطای اتصال به پایگاه داده:
- اطلاعات اتصال در `config/database.php` را بررسی کنید

- حساب ممکن است قفل شده باشد
- کوکی‌ها و cache مرورگر را پاک کنید
